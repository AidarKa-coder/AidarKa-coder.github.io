# Интерактивная открытка

## Что внутри
- `index.html` — весь сайт;
- `waterfall.gif` — оригинальная анимация водопада;
- `generate_qr.py` — создание QR-кода после публикации сайта.

## Как проверить
Откройте `index.html` двойным щелчком. Все сценарии работают локально и на телефоне.

## Как получить публичную ссылку

### Самый простой способ: Netlify Drop
1. Распакуйте ZIP.
2. Откройте сайт Netlify Drop.
3. Перетащите папку `interactive_postcard` в окно загрузки.
4. Сервис выдаст публичную HTTPS-ссылку.

### Через GitHub Pages
1. Создайте новый публичный репозиторий.
2. Загрузите `index.html` и `waterfall.gif` в корень.
3. В Settings → Pages выберите ветку `main` и папку `/root`.
4. GitHub выдаст ссылку.

## Как сделать QR-код
После получения ссылки:

```bash
pip install qrcode[pil]
python generate_qr.py https://ваша-ссылка-на-сайт.ru
```

Появится файл `qr_postcard.png`.

Важно: QR-код нельзя корректно создать заранее без итоговой публичной ссылки.
